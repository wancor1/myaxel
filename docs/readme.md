Programming Language

## Name Origin

I have never seen a programming language with a cute name!
It kind of sounds like a cat, right!

## Why I Made This

- For fun
- I wanted to create a language that is powerful, easy to write, and can be used for many things

Many existing languages tend to be either "easy but limited" or "powerful but complicated"!
This language aims for something in between!
